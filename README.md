# 📄 ATS Resume Analyzer

An intuitive, lightweight web application designed to help job seekers optimize their resumes for **Applicant Tracking Systems (ATS)**. Built with modern HTML5, CSS3, and JavaScript, and ready for deployment on Netlify.

---

## ✨ Features

* 🎯 **Resume & Job Description Analysis:** Compare resume content directly against job descriptions.
* 📊 **Keyword Match Scoring:** Get insights into missing keywords and skills needed to optimize your resume.
* ⚡ **Fast & Lightweight:** Built using standard web technologies with no heavy dependencies.
* 🚀 **Netlify Ready:** Configured with `netlify.toml` for seamless continuous deployment.
* 📱 **Responsive Design:** Clean, modern user interface optimized for desktop and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Deployment:** Netlify
